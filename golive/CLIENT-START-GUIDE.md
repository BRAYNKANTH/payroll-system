# Getting started: first day for the client

The site is at **www.wec.lk**. Everything below is done inside the app.

## 1. Sign in and change the owner passwords first
- Sign in as **admin** or **navoj** (both start with the password `demo1234`).
- Open your account menu (top right) and **change the password**. Do this before anything else.

## 2. What is already set up
- **6 hubs:** Jaffna 1, Jaffna 2, Jaffna 3, Chavakachcheri, Kilinochchi 1, Kilinochchi 2.
- **17 managers and promoting managers**, each in their hub, with the teams you gave (whose team each person counts in for commission). One coacher per hub.
- **About 10 sellers under each manager** (2 supervisors and 8 distributors). These are **placeholders** named like "Issany D1" and "Issany S1".
- **A login for every person.** The username starts with a number (for example `4821-issany`). Everyone starts with the password `demo1234`.

## 3. Make it yours (Employees and Users pages)
1. **Employees:** open each placeholder, change the name, phone, bank details and join date. Remove the ones you do not need (mark them as left).
2. Move a seller to another manager by changing **Team of**.
3. **Users:** change each person's password, or set a new one. Give each person only their own username and password.
4. Add new people with **Add employee**; create their sign-in on the Users page.

## 4. Pay rules that are already set
- **Distributor:** target Rs 100,000, basic Rs 25,000, 30% of sales above the target, 25% of all sales below it, food Rs 150 a day.
- **Supervisor:** target Rs 120,000, basic Rs 30,000, same rates, food Rs 150 a day **only when more than 24 days are worked**.
- **Manager:** basic Rs 27,000. **Promoting manager:** basic Rs 30,000 plus a share on the managers directly under them.
- All of these can be changed in **Settings** (Pay defaults) or per person.

## 5. Each person sees
- A **manager** sees the names of his own team only; he opens a person to see the details.
- A **coacher** sees and works with his hub.
- Sellers see only their own page.

## Keep safe
- Never share the list of usernames and passwords by chat or e-mail.
- Change `demo1234` for everyone as soon as possible.
